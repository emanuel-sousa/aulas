# Aulas de Matemática

Este repositório reúne páginas HTML com aulas de Matemática em formato de lousa digital/slides.

As páginas foram feitas para estudo, revisão e apresentação em sala ou em casa. Cada aula funciona diretamente no navegador, sem precisar instalar nada.

## Aulas disponíveis

- **Aula 1:** Expressões algébricas
- **Aula 2:** Sequências numéricas e termos semelhantes

## Como acessar

Depois que o GitHub Pages estiver ativado, as aulas poderão ser acessadas pelos links:

- Aula 1: `https://emanuel-sousa.github.io/aulas/index.html`
- Aula 2: `https://emanuel-sousa.github.io/aulas/aula2.html`

## Recursos das aulas

- Slides em HTML, CSS e JavaScript
- Botões para avançar e voltar
- Navegação pelo teclado
- Visual colorido e didático
- Conteúdo voltado para alunos do 7º ano
- Exercícios rápidos com gabarito

## Como usar

Abra o arquivo da aula no navegador e use os botões:

- **Próximo →** para avançar
- **← Anterior** para voltar

Também é possível usar o teclado:

- Seta direita ou espaço: próximo slide
- Seta esquerda: slide anterior
- Home: primeiro slide
- End: último slide

## Objetivo

O objetivo deste material é explicar conteúdos matemáticos de forma simples, visual e passo a passo, facilitando a compreensão de alunos que estão começando a estudar expressões algébricas, sequências e padrões.
